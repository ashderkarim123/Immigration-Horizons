# Immigration Horizons Operations Workflow

Version: 1.0

---

# Purpose

This document defines the operational workflow of Immigration Horizons.

It describes how leads, clients, petitions, tasks, approvals, and deliveries move through the system.

Every module in the Admin Dashboard must follow this workflow.

# Lead Management

### Purpose

Manage all incoming inquiries.

### Sources

- Website Form
- Facebook
- Instagram
- WhatsApp
- Google Ads
- Referral
- Manual Entry

### Workflow

New

↓

Assigned

↓

Contacted

↓

Qualified

↓

Consultation Scheduled

↓

Proposal Sent

↓

Won / Lost

↓

Client Created

### Rules

- Every lead has one owner.
- Every assignment notifies the assignee.
- Every interaction is logged.
- Lost leads remain searchable.

---

# Client Onboarding

After a lead is won:

- Create Client Profile
- Generate Client ID
- Upload Initial Documents
- Assign Case Manager
- Create First Case
- Enable Client Portal (future)

---

# Case Management

Each client may have multiple cases.

Examples

- EB-2 NIW
- EB-1A
- EB-1B
- EB-1C
- O-1

Each case stores:

- Status
- Team
- Timeline
- Deadlines
- Documents
- Tasks

↓

↓

↓

Final Review

↓

↓

↓

Submission

↓
