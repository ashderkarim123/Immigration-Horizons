# Immigration Horizons SEO Guidelines

Version: 1.0

---

# Purpose

Defines the SEO standards for the website and CMS.

---

# Objectives

- Increase organic traffic
- Improve keyword rankings
- Generate qualified leads
- Build topical authority

---

# Technical SEO

Every page must include

- Title
- Meta Description
- Canonical URL
- Open Graph
- Twitter Card
- Schema
- Breadcrumb
- Robots Compliance

---

# Content SEO

Every page should have

- One H1
- Logical heading structure
- Internal links
- External authority links
- Optimized images
- FAQs where appropriate

---

# Blog Standards

Every article includes

- Featured Image
- Author
- Publish Date
- Reading Time
- TOC
- Related Articles
- CTA
