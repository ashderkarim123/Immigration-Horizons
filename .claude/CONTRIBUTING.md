# CONTRIBUTING.md

# Development Standards

Version: 1.0

---

# Purpose

Defines the coding and collaboration standards for the Immigration Horizons project.

---

# Branch Strategy

main

Production-ready code

develop

Integration branch

feature/*

New features

fix/*

Bug fixes

hotfix/*

Production fixes

---

# Commit Messages

Examples

feat: add lead assignment module

fix: resolve dashboard sidebar issue

refactor: simplify petition workflow

docs: update API documentation

---

# Coding Standards

- TypeScript only
- Reusable components
- Small functions
- Strong typing
- No duplicate logic
- Clean folder structure

---

# Pull Requests

Before merging:

- Build passes
- Lint passes
- Tests pass
- Documentation updated
- UI reviewed
- No unnecessary files

---

# Code Reviews

Review for:

- Functionality
- Performance
- Security
- Accessibility
- Maintainability

---

# Documentation

Update documentation whenever:

- Database changes
- API changes
- Workflow changes
- New modules
- Major UI changes

---

# Dependencies

Only add dependencies when necessary.

Prefer existing libraries already used in the project.

---

# Quality Standards

Every feature should be:

- Reusable
- Tested
- Documented
- Responsive
- Accessible
- Production-ready

---

# Success Criteria

Maintain a clean, scalable, and consistent codebase that supports long-term development.
