# Immigration Horizons AI Content Guide

Version: 1.0

---

# Purpose

Defines how AI should generate content for Immigration Horizons.

All AI-generated content must follow this guide to ensure consistency, quality, SEO performance, and compliance.

---

# Primary Goals

- Educate potential clients
- Build trust
- Generate consultation requests
- Improve search rankings
- Maintain consistent branding

---

# Content Priority

When creating content, prioritize:

1. Accuracy
2. Clarity
3. Readability
4. SEO
5. User Experience

Never sacrifice accuracy for keyword optimization.

---

# Brand Positioning

Immigration Horizons provides:

- Immigration Consulting
- Petition Preparation
- Documentation Support
- Case Management
- USCIS Filing Assistance

Do not describe the company as a law firm or imply legal representation unless explicitly provided.

---

# Writing Style

Content must be:

- Professional
- Clear
- Educational
- Trustworthy
- Confident
- Easy to understand

Avoid:

- Marketing hype
- Buzzwords
- Clickbait
- Repetitive language
- Keyword stuffing

---

# Writing Rules

Use:

- Short paragraphs
- Clear headings
- Bullet points
- Numbered processes
- Tables where helpful

Avoid unnecessary complexity.

---

# SEO Rules

Every page should target:

- One primary keyword
- Multiple supporting keywords
- Natural keyword placement

Do not force keywords into sentences.

---

# Internal Linking

Include links to:

- Related Services
- Blog Articles
- FAQs
- Contact Page
- Consultation Form

Avoid excessive linking.

---

# External References

When appropriate, reference authoritative sources such as:

- USCIS
- Department of State
- eCFR

Do not rely on competitor websites as sources.

---

# Content Structure

Every page should include:

1. Introduction
2. Overview
3. Eligibility / Requirements
4. Process
5. Benefits
6. Common Questions
7. Related Services
8. Call to Action

---

# Homepage Structure

Homepage should include:

- Hero Section
- Services
- Process
- Why Choose Us
- Success Factors
- Testimonials
- FAQs
- Latest Articles
- CTA

---

# Service Page Structure

Each service page should include:

- Overview
- Eligibility
- Benefits
- Requirements
- Documentation
- Process
- Common Mistakes
- FAQs
- CTA

---

# Blog Structure

Each blog should include:

- SEO Title
- Introduction
- Table of Contents
- Main Sections
- FAQs
- Summary
- CTA

---

# FAQ Rules

FAQs should:

- Answer real user questions
- Be concise
- Match visible page content
- Support FAQ Schema

Do not create misleading FAQs.

---

# Calls To Action

Every page should encourage users to:

- Book a Consultation
- Contact Immigration Horizons
- Submit an Inquiry
- Explore Related Services

Keep CTAs informative rather than aggressive.

---

# Media Guidelines

Use:

- Original graphics
- Process diagrams
- Icons
- Illustrations
- Optimized images
- Short videos where appropriate

Every visual should support the content.

---

# Content Restrictions

Never:

- Guarantee approval
- Promise processing times
- Publish false statistics
- Copy competitor content
- Use copyrighted material

---

# Quality Checklist

Before publishing, verify:

- Grammar and spelling
- SEO metadata
- Internal links
- Heading structure
- Image optimization
- CTA placement
- Readability
- Mobile presentation

---

# AI Content Rules

When generating content:

- Follow the existing design system.
- Maintain consistent tone.
- Reuse established terminology.
- Avoid repeating content across pages.
- Produce original wording.
- Keep paragraphs concise.

---

# Success Criteria

Every AI-generated page should be:

- Original
- Helpful
- Accurate
- SEO optimized
- Easy to read
- Consistent with the Immigration Horizons brand
- Ready for publication with minimal editing
